# numr Web 0.9.1

- Round values to 0–28 decimal places with `round(x, n)`, using midpoint-to-even rounding. The rounded value is stored for subsequent arithmetic: `rounded = round(1.234567, 4)` followed by `rounded * 10000` gives `12346`.
- Includes the updated numr 0.9.1 core. The web and desktop interfaces are unchanged.
